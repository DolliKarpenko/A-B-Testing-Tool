# A/B Testing Tool
### Goal
Automate the calculation of statistical significance for A/B test results by creating a Python script. Analyze changes in metrics as a result of A/B testing and visualize the results on a dashboard.
### Tech stack:
- SQL for data retrieval
- [Python for statistical calculations and script creation](https://github.com/DolliKarpenko/A-B-Testing-Tool/blob/main/A_B_Testing_Tool.ipynb)
- [Tableau for visualizing results](https://public.tableau.com/views/ABtestdata/ABTestingTool?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)
